# Инструкция по применению миграции базы данных

## Проблема
При обновлении кода бота появились новые поля в базе данных:
- `first_name` в таблице `users`
- новая таблица `game_messages`

Если вы получили ошибку `table users has no column named first_name`, значит нужно выполнить миграцию.

## Как применить миграцию

### Вариант 1: Автоматическая миграция (рекомендуется)

1. Остановите бота (если он запущен)

2. Откройте терминал/командную строку в папке проекта

3. Перейдите в папку `poker`:
   ```bash
   cd poker
   ```

4. Запустите скрипт миграции:
   ```bash
   python migrate_multiple_messages.py
   ```

5. Вы должны увидеть сообщения о создании резервной копии и успешном выполнении миграции

6. Запустите бота снова

### Вариант 2: Удалить базу и начать заново

Если у вас нет важных данных:

1. Остановите бота
2. Удалите файл `poker/poker_bot.db`
3. Запустите бота - база данных создастся автоматически с новой структурой

## Что делает миграция

✅ Создает резервную копию базы данных (poker_bot_backup_*.db)
✅ Добавляет поле `first_name` в таблицу `users`
✅ Создает таблицу `game_messages` для отслеживания всех сообщений
✅ Переносит существующие message_id в новую таблицу

## Примечание

После миграции бот будет:
- Показывать имена пользователей (first_name) вместо @username в интерфейсе
- Удалять ВСЕ сообщения при обновлении/удалении стола (не только одно)
