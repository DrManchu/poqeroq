# 🃏 Telegram Покер Бот

Telegram бот для игры в Техасский Холдем Покер.

## 📋 Требования

- Python 3.11+
- Доступ в интернет
- Токен бота от @BotFather

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd poker
pip3 install -r requirements.txt
```

### 2. Настройка токена

Откройте файл `config.py` и укажите токен вашего бота:

```python
BOT_TOKEN: str = "ВАШ_ТОКЕН_БОТА"
```

### 3. Проверка подключения

Перед запуском бота проверьте, работает ли токен:

```bash
python3 test_bot.py
```

Вы должны увидеть:
```
✅ Бот успешно подключен!
   ID: ...
   Имя: ...
   Username: @your_bot
```

### 4. Запуск бота

```bash
python3 bot.py
```

Или используйте скрипт:

```bash
./start.sh
```

## 🎮 Команды бота

### В личных сообщениях:
- `/start` - Приветствие и информация о балансе
- `/balance` - Показать свой баланс и статистику
- `/top` - Топ игроков по балансу
- `/help` - Справка по игре

### В групповых чатах:
- `/poker` - Создать новый стол
- `/join` - Присоединиться к столу
- `/leave` - Покинуть стол

## ⚙️ Настройка

Все настройки находятся в файле `config.py`:

- `BOT_TOKEN` - Токен бота
- `STARTING_BALANCE` - Начальный баланс (по умолчанию 10000)
- `BLINDS` - Малый и большой блайнды (50, 100)
- `MIN_PLAYERS` - Минимум игроков (2)
- `MAX_PLAYERS` - Максимум игроков (8)
- `JOIN_TIMEOUT` - Время ожидания игроков (60 сек)
- `TURN_TIMEOUT` - Время на ход (60 сек)

## 🔧 Устранение неполадок

### Бот не отвечает

1. **Проверьте токен бота:**
   ```bash
   python3 test_bot.py
   ```

2. **Проверьте интернет-соединение:**
   ```bash
   curl -I https://api.telegram.org
   ```

3. **Проверьте логи:**
   Логи сохраняются в файл `poker_bot.log`

### Ошибка "ModuleNotFoundError"

Установите зависимости:
```bash
pip3 install -r requirements.txt
```

### Бот падает при запуске

Проверьте, что:
- У вас Python 3.11 или новее
- Установлены все зависимости
- Токен бота правильный и активный
- Есть доступ в интернет

## 📝 Логи

Логи бота сохраняются в:
- Консоль (stdout)
- Файл `poker_bot.log`

Для просмотра логов в реальном времени:
```bash
tail -f poker_bot.log
```

## 🗄️ База данных

Бот использует SQLite базу данных `poker_bot.db` для хранения:
- Балансов игроков
- Статистики игр
- Состояния текущих игр
