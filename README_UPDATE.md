# ⚠️ ВАЖНО: Обновление базы данных

## После обновления кода (git pull) необходимо выполнить миграцию!

Если вы получили ошибку:
```
OperationalError: table users has no column named first_name
```

**Выполните миграцию базы данных:**

1. Остановите бота
2. Перейдите в папку `poker`:
   ```bash
   cd poker
   ```
3. Запустите миграцию:
   ```bash
   python migrate_multiple_messages.py
   ```
4. Запустите бота снова

Подробная инструкция: [MIGRATION_INSTRUCTIONS.md](MIGRATION_INSTRUCTIONS.md)

## Что нового в этом обновлении

### ✅ Исправлены критические баги:

1. **Множественные сообщения**: Теперь при обновлении/удалении стола удаляются ВСЕ сообщения, а не только одно
